# 📡 راه‌اندازی کانال و ربات — گام‌به‌گام

هر چیزی که در تلگرام باید دستی تنظیم شود، اینجا آماده و کپی‌شدنی است.
ترتیب را رعایت کن.

---

## ۱) تنظیم ربات در BotFather

```
/setuserpic      → brand/bot_avatar.jpg
/setname         → V-CORP: OUTBREAK
/setabouttext    → بازی متنی گروهی بقا، آلودگی و خیانت. مرا به گروه اضافه کن.
/setdescription  → (متن زیر)
/setcommands     → (فهرست زیر)
/setjoingroups   → Enable
/setprivacy      → Disable
```

> `/setprivacy → Disable` لازم است، وگرنه ربات پیام‌های معمولی گروه را
> نمی‌بیند و دستورهای بدون منشن کار نمی‌کنند.

### متن description

```
☣️ شهر سقوط کرده. ویروس VX-13 مرز انسان و سلاح را پاک کرده.

🧬 آلوده شو و قدرت بگیر — با شمارش معکوس
🦸 قدرت‌های V-SERUM، هرکدام با ضعف مشخص
🏢 سازمان بساز، بجنگ، خیانت کن
⚔️ گودال (PvP) · ☣️ قرنطینه · 🚚 کاروان

بازی کامل داخل گروه انجام می‌شود.
```

### فهرست دستورها (`/setcommands`)

این دقیقاً همان چیزی است که ربات موقع بالا آمدن خودش ثبت می‌کند،
اما اگر خواستی دستی هم بگذاری:

```

me - 🧬 پروفایل

modes - 🎮 حالت‌های گروهی
duel - ⚔️ دعوت به گودال
arena - 🏆 رتبه‌بندی گودال
lockdown - ☣️ پروتکل قرنطینه (گروهی)
convoy - 🚚 کاروان — فرار گروهی
boss - 👹 تهدید بزرگ
world - 🌎 وضعیت جهان
shop - 💰 فروشگاه

```


## ۳) ترتیب پست‌های اولیه

پست‌های آماده در `channel_posts.md` هستند. ترتیب پیشنهادی:

1. **پست معرفی** (`channel_banner.jpg`) → **پین کن**
2. پست معرفی گودال/PvP (`hollow_ring.jpg`)
3. آموزش حرکات دوئل (`moves_chart.jpg`)
4. معرفی قرنطینه — پست ۶ در `channel_posts.md`
5. معرفی کاروان — پست ۷ (`convoy_banner.jpg`)
6. معرفی بستیاری — پست ۸ (پرتره‌های باس)

بعد از آن: قالب رویداد جهانی و گزارش هفتگی به‌صورت دوره‌ای.

---

## ۴) اتصال کانال به ربات (اختیاری ولی توصیه‌شده)

ربات را در کانال **ادمین** کن (فقط دسترسی Post Messages).
سپس در محیط اجرا:

```bash
CHANNEL_ID=@vcorp_outbreak
```

> در حال حاضر ربات پستِ خودکار در کانال نمی‌گذارد. این متغیر برای
> نسخه بعدی رزرو شده تا رویدادهای جهانی و مرگ باس‌ها به‌طور خودکار
> اعلام شوند. تا آن زمان پست‌ها دستی از `channel_posts.md` گذاشته می‌شوند.

## ۵) اجرای ربات روی سرور

```bash
cd /path/to/hermes1
python3 -m venv .venv
.venv/bin/pip install -U aiogram aiosqlite
BOT_TOKEN=<توکن> DB_PATH=./vcorp.sqlite3 ADMIN_IDS=<آیدی عددی خودت> \
  .venv/bin/python -m vcorp
```

برای اجرای دائمی، بخش `systemd` در `README.md` را ببین.

> ⚠️ **مهم:** توکنی که در چت فرستادی لو رفته است. حتماً در BotFather
> `/revoke` بزن و توکن تازه را فقط در متغیر محیطی سرور بگذار.
