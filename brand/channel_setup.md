# 📡 راه‌اندازی کانال و ربات — گام‌به‌گام

هر چیزی که در تلگرام باید دستی تنظیم شود، اینجا آماده و کپی‌شدنی است.
ترتیب را رعایت کن.

---

## ۱) تنظیم ربات — <b>خودکار</b>

**دیگر لازم نیست اکثر این‌ها را دستی بزنی.** ربات موقع بالا آمدن خودش
این‌ها را روی تلگرام ست می‌کند (`vcorp/branding.py`):

| مورد | وضعیت |
|---|---|
| نام ربات | ✅ خودکار |
| about / description | ✅ خودکار |
| فهرست دستورها (گروه) | ✅ خودکار |
| فهرست دستورها (خصوصی) | ✅ خودکار |
| دکمه منو | ✅ خودکار |
| دسترسی‌های پیشنهادی ادمین | ✅ خودکار |
| عکس پروفایل | ⬅️ دستی (زیر) |
| privacy mode | ⬅️ دستی (زیر) |

### فقط دو کار دستی در BotFather

```
/setuserpic   → brand/bot_avatar.jpg
/setprivacy   → Disable
```

> `/setprivacy → Disable` حیاتی است: بدون آن ربات پیام‌های معمولی گروه را
> نمی‌بیند و دستورها کار نمی‌کنند. `tools/preflight.py` این را چک می‌کند
> و اگر درست نباشد هشدار می‌دهد.

## ۳) ترتیب پست‌های اولیه

پست‌های آماده در `channel_posts.md` هستند. ترتیب پیشنهادی:

1. **پست معرفی** (`channel_banner.jpg`) → **پین کن**
2. پست معرفی گودال/PvP (`hollow_ring.jpg`)
3. آموزش حرکات دوئل (`moves_chart.jpg`)
4. معرفی قرنطینه — پست ۶ در `channel_posts.md`
5. معرفی کاروان — پست ۷ (`convoy_banner.jpg`)
6. معرفی بستیاری — پست ۸ (پرتره‌های باس)

بعد از آن: قالب رویداد جهانی و گزارش هفتگی به‌صورت دوره‌ای.

## ۴) اتصال کانال به ربات (اعلام خودکار)

۱. ربات را در کانال **ادمین** کن (فقط Post Messages کافی است).
۲. در `.env` بگذار:

```
CHANNEL_ID=@vcorp_outbreak
```

بعد از آن ربات این‌ها را **خودکار** در کانال اعلام می‌کند:

- 🏆 کشته شدن هر باس جهانی — همراه با پرتره همان باس و نام بیشترین آسیب‌زننده
- ☣️ پایان هر دور قرنطینه
- 🚚 سرنوشت هر کاروان

اگر `CHANNEL_ID` را نگذاری، هیچ اتفاقی نمی‌افتد و ربات عادی کار می‌کند.
اگر کانال اشتباه باشد، ربات بعد از اولین خطا اعلام‌ها را خودش خاموش
می‌کند تا لاگ پر از ارور نشود.

> اعلام‌ها عمداً کم‌اند. کانالی که برای هر تاس پیام بدهد، mute می‌شود.

## ۵) اجرای ربات روی سرور

توکن از فایل `.env` خوانده می‌شود (که در `.gitignore` است و هرگز کامیت
نمی‌شود). پس فقط:

```bash
cd /path/to/hermes1
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# توکن را در .env بگذار (نمونه: .env.example)
.venv/bin/python tools/preflight.py     # چک آمادگی
.venv/bin/python -m vcorp               # اجرا
```

`preflight.py` قبل از اجرا توکن، دیتابیس، تصاویر، کانال و اتصال به تلگرام
را چک می‌کند و دقیقاً می‌گوید چه چیزی کم است.

### گرفتن آیدی ادمین

ربات را بالا بیاور و در گروه یا PV بزن:

```
/whoami
```

عدد را در `.env` بگذار (`ADMIN_IDS=...`) و ربات را ری‌استارت کن.

برای اجرای دائمی، بخش `systemd` در `README.md` را ببین.

> ⚠️ **مهم:** توکنی که در چت فرستادی لو رفته است. حتماً در BotFather
> `/revoke` بزن و توکن تازه را فقط در متغیر محیطی سرور بگذار.
